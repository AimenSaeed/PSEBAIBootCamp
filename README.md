
# School Manager

A Python-based school management application.

## Features
- Add students and marks.
- Generate report cards.
- Rank students by average.
- Save and load records using JSON.
- Generate teacher comments.

## Requirements
Python 3 and pytest.

## Run the project

1. Create a virtual environment.
2. Install dependencies using pip install -r requirements.txt.
3. Run python main.py.
4. Run pytest -v to execute tests.
